        A folder of its own: it is created if it does not exist yet. Changes apply immediately, with no restart needed.

        Refused: a whole drive (C:\ or D:\), the Windows and Program Files folders, your user profile folder itself, app-data and credential folders, browser profiles, Trike Trails / Antigravity / Gemini, and Tala's own install or data folder.
