Tool: vault_read

<p><strong>vault_read</strong> is a callable tool in Tala's registry. Read one private vault document by id. Refused when the active model is remote unless that document carries an explicit grant.</p><p>Call it as <code>vault_read(doc_id*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>doc_id</code> (string, required)</li></ul><p>Unseals and returns the document body. A local model reads freely. A remote model is refused unless the user has granted that specific document remote access, and the refusal says so rather than returning empty -- a refusal that looks like an empty document teaches the caller the wrong thing.</p><p>Implemented in <code>sdk.agent.vault_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
