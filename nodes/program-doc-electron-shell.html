The Electron shell owns the desktop process boundary. It starts the UI, loads preload and IPC handlers, resolves app user-data paths, and bridges renderer requests to backend RPC surfaces. Documentation for this area should distinguish main-process authority from renderer display behavior and should preserve cross-platform user-data path resolution.
