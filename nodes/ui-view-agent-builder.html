Reconciliation

This node was reconciled against system-architecture-contract on 2026-09-08 at commit b043043f45d0. That contract is authoritative on:

  • which stores own which records, and what backup and restore each requires
  • the three security layers — renderer isolation, the IPC surface, and host command execution — and which of them protects what
  • how chat, goals, workflows, DAGs, crews, swarms and scheduled jobs reach a tool, and what verifies the result
  • capability maturity: implemented, tested, live-verified, experimental, or unavailable, with the evidence named
  • which node types may execute, and the authority required to run them

Where this node and the contract disagree on those subjects, the contract is current and this node is not. On everything else this node remains the better source — the deference is bounded deliberately, because a blanket one would discard what this document knows and the contract does not.

Regenerate the contract with python scripts/generate_architecture_contract.py, or call docs.regenerate_contract. It also refreshes daily on its own, writing only when the description actually changed.
