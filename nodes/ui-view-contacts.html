UI View: Contacts Directory

Peer identity and transport: username, wallet address, endpoint, shared secret, and sharing permissions. Reached: Sidebar rail, 9th icon (people).

The operator describes this screen as: “When finally online we will be able to add people to this based on their remote wallet ID. This also is part of what allows remote users to access local user skills.”

Behaviour notes

  • Being a contact confers no access. Access is granted per resource, by invitation.
