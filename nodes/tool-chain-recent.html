Tool: chain_recent

<p><strong>chain_recent</strong> is a callable tool in Tala's registry. List the newest blocks on your local blockchain (default 10, at most 50): each block's index, time, signer, and its transactions (id, type, creator, whether it carries a document). Never returns document contents. Read-only.</p><p>Call it as <code>chain_recent(limit)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>limit</code> (integer, optional)</li></ul><p>``limit`` is clamped to 1..50. Returns the newest blocks, oldest first, as summaries. Document bodies are never included.</p><p>Implemented in <code>sdk.agent.chain_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
