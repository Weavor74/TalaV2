Harness: Tool Selection

tool_selection.py — choose which tools a given turn actually offers the model.

It lives at python/harness/tool_selection.py within the Python harness, the backend that runs the system.

Classes it defines: ToolIndex — Keyword index over the registry, plus any authored keyword supplement. (methods: score()).

Functions it exposes: select_tool_names() — Names to offer this turn: core, plus anything already used this request, plus the highest-scoring remainder up to `budget`.; budget_for() — Per-turn tool budget, overridable per provider via `tool_budget`.; select_specs() — Filter already-built tool specs down to the selection.; conversation_text() — The text selection is scored against: the last few non-system messages..
