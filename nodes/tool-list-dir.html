Tool: list_dir

<p><strong>list_dir</strong> is a callable tool in Tala's registry. List a folder on your computer with sizes and modified times. recursive=true walks subfolders; sort_by is name, size (largest first) or modified (newest first); files_only skips folders; limit caps the rows returned. Your workspace is the working folder the user chose for you in Settings > Workspace; relative paths are relative to it. If no workspace is configured the tool says so: tell the user to choose one there. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>list_dir(path, recursive, pattern, sort_by, limit, files_only)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>path</code> (string, optional)</li><li><code>recursive</code> (boolean, optional)</li><li><code>pattern</code> (string, optional)</li><li><code>sort_by</code> (string, optional)</li><li><code>limit</code> (integer, optional)</li><li><code>files_only</code> (boolean, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
