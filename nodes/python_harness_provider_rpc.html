It lives at python/harness/provider_rpc.py within the Python harness, the backend that runs the system.

Functions it exposes: handle_inference_get_providers() — retrieve configured inference providers; handle_inference_save_providers() — persist inference providers ordering and config; handle_inference_get_embedded_status() — return progress of default embedded model download; handle_inference_trigger_download() — start downloading default embedded model; handle_inference_get_engines() — get supported embedded engines and installation status; handle_inference_install_engine() — trigger pip installation of an engine; handle_inference_get_engine_install_progress() — get engine installation progress; handle_inference_detect_local_providers() — on-demand scan of local inference engines.
