token_counter.py — Tala Cognitive Engine Room: Token Counting Interceptor ========================================================================= Every prompt MUST pass through this module before reaching vLLM.

It lives at python/harness/token_counter.py within the Python harness, the backend that runs the system.

Classes it defines: InsufficientTokenBalanceError — Raised when the wallet's real TalaCoin balance cannot cover the cost of a cross-node inference call.; TokenCountError — Raised when token counting itself fails in an unrecoverable way.; TokenCheckResult — Immutable result returned by :func:`count_and_check`..
