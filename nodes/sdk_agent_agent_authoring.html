sdk/agent/agent_authoring.py ============================ Tools that let Tala compose multi-agent work rather than only execute it.

It lives at sdk/agent/agent_authoring.py within the agent SDK.

Functions it exposes: list_agents() — list available agent personas; create_agent() — define a new agent persona; create_swarm_topology() — author a swarm topology as an HTML-NN; start_swarm() — launch a swarm run; discover_mcp_servers_tool() — find MCP servers configured elsewhere on this machine; refresh_mcp_tools_tool() — re-register connected MCP servers' tools; control_swarm() — stop or hold a running swarm; export_trajectories() — assemble past runs into analysable records.
