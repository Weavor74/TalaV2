Tool: list_executable_nodes

<p><strong>list_executable_nodes</strong> is a callable tool in Tala's registry. List the HTML Neural Nodes that can actually be executed -- compiled workflows with execution authority -- with their names and step counts.</p><p>It takes no arguments: <code>list_executable_nodes()</code>.</p><p>list_neural_nodes returns everything, and the overwhelming majority of nodes are documentation that cannot be run. This narrows it to what execute_node will accept, so a plan is not built around a node that will be refused.</p><p>Implemented in <code>sdk.agent.node_execution</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
