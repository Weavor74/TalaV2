UI View: Research Library

Search the web and Tala's own memory together, read a result in full, and distil selected results into a Neural Node. Reached: Sidebar rail, 3rd icon (book). Titled Evidence Browser.

The operator describes this screen as: “This is the research view, it is meant to work like NotebookLM. One of the key features is that it will be able to use the search engine that the user adds with a search API in a later tab.”

3 known defect(s) affect this screen; see the Known defects section before relying on it.

Known defects

  • UI-018: a failing search provider silently degrades to DuckDuckGo scraping.
  • UI-019: the /search substring misroutes most commercial search APIs.
  • UI-022: no way to flag a result into chat.
