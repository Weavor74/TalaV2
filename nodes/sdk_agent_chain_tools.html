SDK Agent: Chain Tools

sdk.agent.chain_tools -- read-only chain tools Tala can call.

It lives at sdk/agent/chain_tools.py within the agent SDK.

Functions it exposes: chain_status() — is the local chain node up, and is the ledger valid; chain_recent() — what was anchored most recently; chain_read() — is this record on the chain, and what is it; chain_verify() — audit the ledger without trusting the node.
