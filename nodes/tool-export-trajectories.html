Tool: export_trajectories

<p><strong>export_trajectories</strong> is a callable tool in Tala's registry. Export what actually happened in past runs - conversation turns with their tool calls, or autonomous task runs with their events - as analysable records.</p><p>Call it as <code>export_trajectories(kind, since_hours, limit, include_content, tool_calls_only)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>kind</code> (string, optional)</li><li><code>since_hours</code> (string, optional)</li><li><code>limit</code> (string, optional)</li><li><code>include_content</code> (string, optional)</li><li><code>tool_calls_only</code> (string, optional)</li></ul><p>kind is "conversation" or "task". They are separate streams and are not joined: a chat session and an autonomous task share no key in the schema, and stitching them on a guess would invent history. include_content defaults to FALSE. Conversation turns contain everything Weavor has ever said, so the default is structure plus tool calls without the prose -- enough to study which tools were reached for and how often a call came back an error. Pass True only when the prose is genuinely what is being studied. Returns a summary alongside the records: the tool histogram is usually the point.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
