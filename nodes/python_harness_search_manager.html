search_manager.py — Tala Cognitive Engine Room: Search Providers & Web Crawler ============================================================================= Orchestrates prioritized web search providers and falls back to direct web crawling if no providers are present.

It lives at python/harness/search_manager.py within the Python harness, the backend that runs the system.

Classes it defines: SearchOutcome — The result of a search *and* what happened on the way to it. (methods: degraded(), error_summary()); SearchManager — Manages search queries via prioritized API providers or raw crawler failovers. (methods: query(), query_detailed()).

Functions it exposes: get_search_providers() — Retrieve all configured search providers sorted by priority from DB.; crawl_web() — Crawl DuckDuckGo HTML search directly as a fallback..
