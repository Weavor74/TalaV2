Validation Bridge

The Validation Bridge documents test.run_validation. It runs allowlisted validation commands such as python -m py_compile and pytest-style commands. Arbitrary shell commands are not allowed. Validation reports command, exit code, stdout, stderr, timeout status, and success. Tala should use this bridge after code mutation or documentation generation whenever a validation command is relevant.
