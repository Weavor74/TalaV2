Tool: desktop_stop

<p><strong>desktop_stop</strong> is a callable tool in Tala's registry. Stop the active native desktop agent immediately. Its pending model request is cancelled and no further input is sent.</p><p>It takes no arguments: <code>desktop_stop()</code>.</p><p>Can run independently while desktop_run holds the input lock.</p><p>Implemented in <code>sdk.agent.desktop_agent</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
