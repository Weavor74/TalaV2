UI View: Editor

Tala's original purpose: opening and editing files of any type, with the editor refusing to write anything it cannot safely write. Reached: No sidebar entry by design. It is the centre pane the Explorer opens a file into.

The operator describes this screen as: “The editing section was meant to be the center pane. Her original usage intent was a method to edit files and documents. Be them txt, images or whatever. This included code.”

3 known defect(s) affect this screen; see the Known defects section before relying on it.

Behaviour notes

  • Files are classified as text, image or binary from the extension. An unknown extension is treated as binary, because guessing wrong towards text is what corrupts files.
  • Images are read with encoding=base64 and shown as a data URI. file:read already accepted an encoding, so carrying bytes safely needed no new IPC channel.
  • Code is named by language on the badge - Python, Rust, SQL. There is no syntax highlighting.
  • Saving is refused for images, binaries, and any file whose read failed. Before this, opening a PNG read it as UTF-8 into the textarea and Save wrote the mangled text back, destroying the file (UI-114).

Known defects

  • No syntax highlighting. Code opens as plain monospace text with a language label only.
  • No image editing - images are read-only, and there is no crop, resize or annotate.
  • No file import into the Vault from here; vault documents are created in the Vault view and are text only.
