UI View: Editor

Tala's original purpose: editing files and documents of any type. Reached: No sidebar entry by design. It is the centre pane the Explorer opens a file into.

The operator describes this screen as: “The editing section was meant to be the center pane. Her original usage intent was a method to edit files and documents. Be them txt, images or whatever. This included code.”

2 known defect(s) affect this screen; see the Known defects section before relying on it.

Behaviour notes

  • Preview is gated to .md and .html only.
  • Steven wants all formats covered, image and text.

Known defects

  • UI-114: the editor is a textarea. Code has no language awareness and images cannot open at all.
  • UI-115: the Explorer never lists a user file, so the editor is unreachable by its only intended route.
