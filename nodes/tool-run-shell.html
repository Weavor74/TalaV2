Tool: run_shell

<p><strong>run_shell</strong> is a callable tool in Tala's registry. Run a shell command on your computer and get stdout, stderr and the exit code. The shell is PowerShell on Windows and bash on Linux/macOS; the result's 'shell' field says which, so write that syntax. cwd defaults to the workspace. timeout_seconds defaults to 60; use start_job for anything longer than a few minutes. Your workspace is the working folder the user chose for you in Settings > Workspace; relative paths are relative to it. If no workspace is configured the tool says so: tell the user to choose one there. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>run_shell(command*, cwd, timeout_seconds)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>command</code> (string, required)</li><li><code>cwd</code> (string, optional)</li><li><code>timeout_seconds</code> (integer, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
