Tool: run_shell

<p><strong>run_shell</strong> is a callable tool in Tala's registry. Run a PowerShell command on your computer (Windows) and get stdout, stderr and the exit code. Write PowerShell syntax. cwd defaults to the workspace. timeout_seconds defaults to 60; use start_job for anything longer than a few minutes. Your workspace is your own working folder on this computer (D:\TalaWorkspace unless configured otherwise); relative paths are relative to it. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>run_shell(command*, cwd, timeout_seconds)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>command</code> (string, required)</li><li><code>cwd</code> (string, optional)</li><li><code>timeout_seconds</code> (integer, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>.
