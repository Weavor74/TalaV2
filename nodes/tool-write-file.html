Tool: write_file

<p><strong>write_file</strong> is a callable tool in Tala's registry. Create or overwrite a text file on your computer (parent folders are created). Set append=true to add to the end instead. Your workspace is the working folder the user chose for you in Settings > Workspace; relative paths are relative to it. If no workspace is configured the tool says so: tell the user to choose one there. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>write_file(path*, content*, append)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>path</code> (string, required)</li><li><code>content</code> (string, required)</li><li><code>append</code> (boolean, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
