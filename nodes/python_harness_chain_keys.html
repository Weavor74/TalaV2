Harness: Chain Keys

chain_keys.py — obtaining a peer's signing key, and deciding whether to trust it.

It lives at python/harness/chain_keys.py within the Python harness, the backend that runs the system.

Functions it exposes: identity() — This node's own signing key, for handing to a peer.; fetch() — Obtain a peer's signing key and prove they hold it.; offer() — Record a key handed over directly rather than fetched.; offers() — Keys that have been obtained, and what was decided about each.; trust() — Admit an offered key as a permitted signer.; reject() — Refuse an offered key, and withdraw it if it was previously trusted.; retire_own_key() — Retire this node's own signing key and publish that fact.; retired_keys() — Keys known to have retired themselves, from the offers record..
