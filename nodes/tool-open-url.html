Tool: open_url

<p><strong>open_url</strong> is a callable tool in Tala's registry. Open a web page or website in the user's own visible default web browser: use this when asked to open a browser, a website, a link or a page. Takes a web address (https://...); with none it opens a blank page. Unlike browser_navigate, which is headless and shows nothing, the user sees this one.</p><p>Call it as <code>open_url(url)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>url</code> (string, optional)</li></ul><p>NAME open_url - show a web page in the user's default browser SYNOPSIS open_url(url: str | None = None) -> dict[str, Any]</p><p>Implemented in <code>sdk.agent.open_url</code>.
