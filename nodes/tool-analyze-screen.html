Tool: analyze_screen

<p><strong>analyze_screen</strong> is a callable tool in Tala's registry. Capture the user's screen and analyze it with a vision-capable inference provider. Use to see what the user is looking at.</p><p>Call it as <code>analyze_screen(question, provider_id)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>question</code> (string, optional)</li><li><code>provider_id</code> (string, optional)</li></ul><p>Takes a screenshot of the active desktop, sends it to a vision-capable provider (explicit provider_id, or the first configured provider whose model looks multimodal), and returns the model's textual analysis.</p><p>Implemented in <code>sdk.agent.vision_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
