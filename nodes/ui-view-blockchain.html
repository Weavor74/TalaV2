UI View: Blockchain Ledger

Show the local Proof-of-Authority chain as a flow of block cards. Reached: Sidebar rail, 5th icon (chain).

The operator describes this screen as: “This is supposed to track the chain for both Ghost chain and Real Chain. Ghost chain essentially is non-value other than tracking transaction locally. But the real chain only happens when connected to the internet.”

3 known defect(s) affect this screen; see the Known defects section before relying on it.

Behaviour notes

  • Served by blockchain/src/app.js on port 8332.
  • Offline handling is genuinely good: clear error, height 0 (Offline), validity UNREACHABLE.

Known defects

  • UI-023: Ghost/Real is a runtime mode that is never recorded on a transaction.
  • UI-024: no transaction has ever been written in Real mode.
  • UI-025: the renderer hardcodes 127.0.0.1:8332.
