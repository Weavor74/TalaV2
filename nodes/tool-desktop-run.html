Tool: desktop_run

<p><strong>desktop_run</strong> is a callable tool in Tala's registry. Windows-only: perform a complete native computer-use task with a LOCAL Ollama vision model. On other platforms use desktop_observe and desktop_action instead. Owns the screenshot/action/verification loop: prefer this over manually chaining desktop_observe and desktop_action. task is the user's objective. model is an installed Ollama vision model; default qwen2.5vl:3b. No cloud fallback. Returns actual step results and visual completion evidence, or an honest failure. desktop_stop and emergency halt stop execution.</p><p>Call it as <code>desktop_run(task*, model, endpoint, max_steps, cpu_only, success_text)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>task</code> (string, required)</li><li><code>model</code> (string, optional)</li><li><code>endpoint</code> (string, optional)</li><li><code>max_steps</code> (integer, optional)</li><li><code>cpu_only</code> (boolean, optional)</li><li><code>success_text</code> (string, optional)</li></ul><p>Supports primary-monitor desktop applications. Sends no screenshots to cloud providers. Bounds execution to 20 minutes and 40 actions. Completion is model-assessed visual evidence, not an OS assertion. cpu_only=True avoids GPU contention by requesting num_gpu=0. success_text requires a literal final result in blind screen transcription.</p><p>Implemented in <code>sdk.agent.desktop_agent</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
