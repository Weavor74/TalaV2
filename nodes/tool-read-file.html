Tool: read_file

<p><strong>read_file</strong> is a callable tool in Tala's registry. Read a text file from your computer, optionally a line range. Your workspace is the working folder the user chose for you in Settings > Workspace; relative paths are relative to it. If no workspace is configured the tool says so: tell the user to choose one there. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>read_file(path*, start_line, end_line)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>path</code> (string, required)</li><li><code>start_line</code> (integer, optional)</li><li><code>end_line</code> (integer, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
