Tool: update_user_model

<p><strong>update_user_model</strong> is a callable tool in Tala's registry. Distill recent conversations into an updated model of the user (preferences, projects, communication style) and persist it as an HTML-NN learning node. Schedule this with schedule_goal for continuous refinement.</p><p>Call it as <code>update_user_model(focus, max_turns)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>focus</code> (string, optional)</li><li><code>max_turns</code> (string, optional)</li></ul><p>Reads the most recent conversation turns across ALL sessions (in-app chat and messaging channels alike), asks the active LLM to distill durable facts about the user, and stores the result as a 'User Model' learning node so it becomes recallable RAG context in future conversations.</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
