Tool: write_workspace_file

<p><strong>write_workspace_file</strong> is a callable tool in Tala's registry. Write content to a file path within the workspace directory. A small set of files is protected and cannot be overwritten: the training-corpus pipeline under scripts/, the astrology/emotion engine, and the persona and emotion-vocabulary nodes.</p><p>Call it as <code>write_workspace_file(file_path*, content*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>file_path</code> (string, required)</li><li><code>content</code> (string, required)</li></ul><p>Saves content into a file located at a path relative to the workspace root. Refuses to overwrite protected pipeline and identity files.</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
