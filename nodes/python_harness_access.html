Harness: Access

access.py — one grant model, so the three access systems can compose.

It lives at python/harness/access.py within the Python harness, the backend that runs the system.

Classes it defines: Principal — Who is acting. (methods: is_owner()); Decision — Whether an action is permitted, and why..

Functions it exposes: check_constraints() — Whether a grant's constraints are satisfied right now.; validate_constraints() — Whether a set of constraints is *well formed*, without evaluating it.; check() — Decide whether *principal* may do *permission* on *resource*.; grant() — Record a grant.; revoke() — Withdraw a grant.; list_grants() — Every grant, or every grant held by one principal.; resolve() — Compose an explicit grant with a subsystem's own rule..
