Tool: vault_search

<p><strong>vault_search</strong> is a callable tool in Tala's registry. Search inside the user's private vault documents for a phrase. Documents without a grant are withheld when the active model is remote.</p><p>Call it as <code>vault_search(query*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>query</code> (string, required)</li></ul><p>Vault bodies ARE indexed locally into ChromaDB, by Steven's decision: the index holds plaintext and never leaves the machine, which is the trade that makes the vault findable rather than merely storable. This tool opens the documents directly rather than going through that index, so a result is always the current file. Each hit is checked individually, so one withheld document does not hide the rest.</p><p>Implemented in <code>sdk.agent.vault_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
