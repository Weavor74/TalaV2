Tool: diagnose_self

<p><strong>diagnose_self</strong> is a callable tool in Tala's registry. Run a full self-diagnosis: measured subsystem health plus the recent errors and warnings behind it, in one call. Use this when asked what is wrong, or before reporting that something works.</p><p>Call it as <code>diagnose_self(minutes)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>minutes</code> (integer, optional)</li></ul><p>Health alone says a subsystem is degraded; the log says why. Asking for both separately is the common case, so this does it in one call and returns them side by side. Read-only, like the two tools it composes.</p><p>Implemented in <code>sdk.agent.self_diagnosis</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
