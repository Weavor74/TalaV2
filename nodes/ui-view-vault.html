UI View: Vault

Intended as private document storage the local model can reference and nothing leaves. Reached: Sidebar rail, 8th icon (person).

The operator describes this screen as: “Vault section does not work at all. It is meant for storage of editable private documents. Things the local LLM could reference, but nothing gets shared outside.”

5 known defect(s) affect this screen; see the Known defects section before relying on it.

Behaviour notes

  • vault:read is path-traversal safe, size-capped, and refuses unless network isolation is active.
  • Vault contents are arbitrary files, a deliberate exception to the HTML-NN mandate.

Known defects

  • UI-036: the view is a static placeholder with no JavaScript. Drop files here has no drop handler.
  • UI-037: there is no write path, so editable documents is impossible.
  • UI-038: no tool exists, so the local model cannot reference vault documents.
  • UI-039: the Network Isolated badge is hardcoded.
  • UI-102: network isolation is never enabled, so vault:read always throws.
