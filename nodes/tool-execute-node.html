Tool: execute_node

<p><strong>execute_node</strong> is a callable tool in Tala's registry. Run the workflow described by an HTML Neural Node, passing optional inputs. Only workflow nodes that declare execution authority can be run; documentation and tool-catalogue nodes cannot. Use list_neural_nodes to find one and read_neural_node to inspect it first.</p><p>Call it as <code>execute_node(node_id*, inputs)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>node_id</code> (string, required)</li><li><code>inputs</code> (object, optional)</li></ul><p>Completes the read/enumerate/write/act set. Tala could already read a node, list nodes and update one, but had no way to run what a node described -- so a compiled workflow node documented how to execute itself to a reader with no mechanism to do so. The workflow specification is read from the node's own node-state block rather than from a JSON sidecar, so the document that was retrieved is the document that runs. Refuses any node whose type is not a workflow, and any node declaring execution authority below 0.5. Returns success=False with the reason rather than raising, and never reports a failed workflow as a successful call.</p><p>Implemented in <code>sdk.agent.node_execution</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
