Tool: create_agent

<p><strong>create_agent</strong> is a callable tool in Tala's registry. Define a new agent persona that swarm nodes can run as. Sets a name, role and system prompt only - it grants no tools, no model and no authority.</p><p>Call it as <code>create_agent(name*, system_prompt*, role, tag)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>name</code> (string, required)</li><li><code>system_prompt</code> (string, required)</li><li><code>role</code> (string, optional)</li><li><code>tag</code> (string, optional)</li></ul><p>Creates a persona a swarm node can be assigned to. It sets voice and framing; it does not widen what the node may do. An existing name is refused rather than overwritten. A persona may be mid-use by a running swarm, and silently replacing its system prompt would change that run's behaviour underneath it.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
