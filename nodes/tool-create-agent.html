Tool: create_agent

<p><strong>create_agent</strong> is a callable tool in Tala's registry. Define a new agent persona that swarm nodes can run as. Sets a name, role, system prompt and optionally a birthdate (ISO date) for its own astrological chart - it grants no tools, no model and no authority. Without a birthdate the persona inherits the install's Primary chart.</p><p>Call it as <code>create_agent(name*, system_prompt*, role, tag, birthdate, birth_hour)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>name</code> (string, required)</li><li><code>system_prompt</code> (string, required)</li><li><code>role</code> (string, optional)</li><li><code>tag</code> (string, optional)</li><li><code>birthdate</code> (string, optional)</li><li><code>birth_hour</code> (number, optional)</li></ul><p>Creates a persona a swarm node can be assigned to. It sets voice and framing; it does not widen what the node may do. An existing name is refused rather than overwritten. A persona may be mid-use by a running swarm, and silently replacing its system prompt would change that run's behaviour underneath it. birthdate (YYYY-MM-DD, optional birth_hour 0-24 UT) gives the persona its own natal chart for the astro-emotion layer. Left unset, the emotion service resolves the install's Primary chart instead (profiles.config.primary_agent_birthdate on the master profile), and only then the canonical origin chart -- Tala's own date is not assumed to be the right default for every install.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
