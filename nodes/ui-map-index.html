UI Map Index

Index of Tala's user interface. Eleven views and eighteen settings panels, with how each is reached. Start here to navigate the UI, then open the ui-view-* node for the screen in question.

Nine views are reached from the left icon rail. The Editor is the centre pane the file Explorer opens into, and the Logs view is vestigial.

Settings panels

Selected by data-panel on #settings-tab-nav: inference, agent, identity, workflows, guardrails, search, system, git, storage, database, runtime, plugins, auth, firewall, channels, logging, architecture, about.

Persistent chrome

  • global-command-bar: Ctrl+P command bar, top centre.
  • workspace-tabs: open tabs, dynamically managed.
  • terminal-panel: bottom dock with TERMINAL 1, Blockchain Node, Python Harness.
  • status-bar: WS status, token balance, active agent, version.
  • Agent Chat: right panel. Green dot means active agent.
