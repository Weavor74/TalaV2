Tool: start_swarm

<p><strong>start_swarm</strong> is a callable tool in Tala's registry. Run a goal through an existing swarm topology, dispatching its start nodes in parallel.</p><p>Call it as <code>start_swarm(goal*, topology_id*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>goal</code> (string, required)</li><li><code>topology_id</code> (string, required)</li></ul><p>Creates the parent task and dispatches every start node at once. The run finalises itself when the last node retires and the synthesised result lands on the parent task. Returns as soon as the run is dispatched -- it does not wait. Follow it with list_active_tasks.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
