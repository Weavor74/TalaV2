Tool: delete_path

<p><strong>delete_path</strong> is a callable tool in Tala's registry. Delete a file (or a folder with recursive=true) on your computer. Always needs approval. Your workspace is the working folder the user chose for you in Settings > Workspace; relative paths are relative to it. If no workspace is configured the tool says so: tell the user to choose one there. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>delete_path(path*, recursive)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>path</code> (string, required)</li><li><code>recursive</code> (boolean, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
