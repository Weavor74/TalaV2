Harness: Channels

python/harness/channels.py — Outside messaging channels ======================================================= Lets Tala be reached from outside the desktop app.

It lives at python/harness/channels.py within the Python harness, the backend that runs the system.

Classes it defines: BaseAdapter — One configured channel. (methods: allowlist(), is_allowed(), start(), stop(), poll(), send(), status()); TelegramAdapter — Long-polls getUpdates; no public URL or webhook required. (methods: poll(), send()); DiscordAdapter — Discord Gateway, drained through poll() so the base loop still owns policy. (methods: start(), stop(), poll(), send()); ChannelManager — Singleton owning every configured channel adapter. (methods: get(), register_broadcast(), start(), reload(), send(), status()).
