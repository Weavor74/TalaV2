Tool: refresh_mcp_tools

<p><strong>refresh_mcp_tools</strong> is a callable tool in Tala's registry. Re-register the tools of every connected MCP server so they can be called.</p><p>It takes no arguments: <code>refresh_mcp_tools()</code>.</p><p>Registers every connected server's tools under {server}__{tool}, and drops the tools of any server that has gone away. Runs at startup and whenever the server set changes, so this is mostly for recovering after a server that was down comes back.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
