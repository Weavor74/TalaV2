Tool: user_profile_lookup

<p><strong>user_profile_lookup</strong> is a callable tool in Tala's registry. Look up one section of the user's own profile: identity, about, roles, skills, projects, connections, preferences, or rp_persona. Use this instead of asking the user to repeat things they have already recorded. Each section is subject to the visibility the user set; personally identifying material is never returned.</p><p>Call it as <code>user_profile_lookup(section*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>section</code> (string, required)</li></ul><p>Only the user's name is injected into the system prompt; everything else about them is fetched on demand through this tool, so that the per-section Privacy & Visibility settings have somewhere to be enforced. Returns {"section", "allowed", "data", "reason"}. A section the user has not shared returns allowed=False with the reason, which is deliberately distinct from an empty section: "they have recorded no skills" and "you may not read their skills" are different facts and must not look alike. pii_vault is never readable. The astrology subsystem reads the date of birth directly from the database and does not go through here.</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
