Tool: manage_inference_engine

<p><strong>manage_inference_engine</strong> is a callable tool in Tala's registry. Check status, install, or update the embedded inference engine.</p><p>Call it as <code>manage_inference_engine(action*, engine_id)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>action</code> (string, required)</li><li><code>engine_id</code> (string, optional)</li></ul><p>Manages local embedded inference engines (e.g. transformers, llamacpp). Supported actions: - "status": Returns the installation status of the engine. - "install": Starts downloading and installing the engine in the background. - "list": Returns a list of all available engines and their status. - action: The action to perform ("status", "install", "list"). - engine_id: The ID of the engine (e.g. "transformers", "llamacpp").</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
