Tool: starcitizen_lookup

<p><strong>starcitizen_lookup</strong> is a callable tool in Tala's registry. Look up canonical Star Citizen universe data: ships and their real stats (mass, cargo, crew, IR/EM emission signatures), star systems, celestial objects, manufacturers, commodities, weapons, factions, and the in-universe written record via galactapedia articles and comm-links. Use this for any question about the Star Citizen universe rather than answering from memory. Resources: celestial-objects, comm-links, commodities, factions, galactapedia, ground-vehicles, items, locations, manufacturers, starsystems, vehicle-weapons, vehicles, weapons.</p><p>Call it as <code>starcitizen_lookup(resource*, query, identifier, limit, full_text)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>resource</code> (string, required)</li><li><code>query</code> (string, optional)</li><li><code>identifier</code> (string, optional)</li><li><code>limit</code> (string, optional)</li><li><code>full_text</code> (string, optional)</li></ul><p>`resource` is one of the keys in _SC_RESOURCES. Provide `query` for a partial-name search, or `identifier` to fetch one record directly by slug/id/code. Results are trimmed to the fields that carry meaning -- a raw vehicle record is several KB of nested port and component trees. Set `full_text=True` on a galactapedia identifier fetch to get the whole article body instead of a summary. Public API, no credentials. Search is rate-limited to 60 requests per minute per IP, so callers should batch rather than loop.</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
