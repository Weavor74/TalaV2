Tool: create_swarm_topology

<p><strong>create_swarm_topology</strong> is a callable tool in Tala's registry. Author a swarm topology: a DAG of named nodes with roles and gate conditions on the edges. Each node may name an agent_id to run as.</p><p>Call it as <code>create_swarm_topology(topology_id*, name*, nodes*, edges*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>topology_id</code> (string, required)</li><li><code>name</code> (string, required)</li><li><code>nodes</code> (array, required)</li><li><code>edges</code> (array, required)</li></ul><p>nodes: [{"id": "scout", "role": "planner", "description": "...", "agent_id": "agent-xxxx"}] -- agent_id is optional edges: [{"from_node": "scout", "to_node": "survey", "condition": "success"}] Validated through the same ``topology_from_spec`` the loader uses, so a topology that would not load back is refused rather than written. Edge conditions are checked against the rules GatedVerifier actually implements. An unknown condition can never pass, and that branch would stall silently on every run.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
