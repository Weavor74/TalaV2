Tool: search_files

<p><strong>search_files</strong> is a callable tool in Tala's registry. Search files under a folder on your computer for text (or a regex with regex=true); names_only=true matches file names instead of contents. Your workspace is the working folder the user chose for you in Settings > Workspace; relative paths are relative to it. If no workspace is configured the tool says so: tell the user to choose one there. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>search_files(query*, path, pattern, regex, names_only)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>query</code> (string, required)</li><li><code>path</code> (string, optional)</li><li><code>pattern</code> (string, optional)</li><li><code>regex</code> (boolean, optional)</li><li><code>names_only</code> (boolean, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
