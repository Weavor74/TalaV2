sdk/agent/web_browser.py ======================== Interactive browser automation tools (Playwright/Chromium).

It lives at sdk/agent/web_browser.py within the agent SDK.

Functions it exposes: browser_navigate() — load a URL in the interactive automation browser; browser_read() — read page text and enumerate interactive elements; browser_click() — click an element by browser_read index or CSS selector; browser_type() — fill an input by browser_read index or CSS selector; browser_screenshot() — capture the automation browser viewport to a PNG; browser_close() — shut down the automation browser session.
