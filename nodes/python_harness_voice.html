Harness: Voice

python/harness/voice.py — Text-to-speech backends ================================================= Synthesises speech and hands it back as base64 audio; the caller (``speak_text`` in sdk/agent/tools.py, ``voice.speak`` over RPC) broadcasts a ``voice.play`` notification so every connected UI plays it.

It lives at python/harness/voice.py within the Python harness, the backend that runs the system.

Functions it exposes: list_backends() — Which TTS backends are usable right now, in resolution order.; synthesize_speech() — Synthesise `text` and return base64 audio..
