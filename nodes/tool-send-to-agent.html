Tool: send_to_agent

<p><strong>send_to_agent</strong> is a callable tool in Tala's registry. Ask another local agent one question and get its reply, synchronously -- your turn waits for the answer. The target agent answers once, in its own configured persona, WITHOUT its own tools (it cannot itself delegate further). Use this to consult a specialist agent by name.</p><p>Call it as <code>send_to_agent(target_agent*, message*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>target_agent</code> (string, required)</li><li><code>message</code> (string, required)</li></ul><p>Phase 3 of the multi-agent plan: one agent consulting another as part of its own turn, not the federation A2A protocol (cross-install, wallet- gated -- wrong trust model for two of the owner's own local agents) and not conversations.py's rooms (a shared thread multiple agents post into automatically; this is a private, on-demand, single-question call).</p><p>Implemented in <code>sdk.agent.agent_reply_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
