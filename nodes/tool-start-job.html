Tool: start_job

<p><strong>start_job</strong> is a callable tool in Tala's registry. Start a long-running shell command (PowerShell on Windows, bash on Linux/macOS) in the background on your computer; returns a job_id. Check it with job_status and end it with stop_job. Your workspace is the working folder the user chose for you in Settings > Workspace; relative paths are relative to it. If no workspace is configured the tool says so: tell the user to choose one there. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>start_job(command*, name, cwd)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>command</code> (string, required)</li><li><code>name</code> (string, optional)</li><li><code>cwd</code> (string, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
