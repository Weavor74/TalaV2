Tool: speak_text

<p><strong>speak_text</strong> is a callable tool in Tala's registry. Speak text aloud to the user through the configured text-to-speech backend (ElevenLabs, OpenAI-compatible, or local offline voice).</p><p>Call it as <code>speak_text(text*, voice, tts_provider_id)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>text</code> (string, required)</li><li><code>voice</code> (string, optional)</li><li><code>tts_provider_id</code> (string, optional)</li></ul><p>Synthesizes the given text with the best available TTS backend (see python/harness/voice.py resolution order) and broadcasts a `voice.play` notification so every connected UI client plays it.</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
