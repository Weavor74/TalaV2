Code Patch Bridge

The Code Patch Bridge documents Tala's bounded code patch tools. code.propose_patch drafts exact-replacement patches without mutating files. code.apply_patch applies exact replacements inside the workspace only. code.propose_file_write and code.write_files support bounded creation of new text files inside the workspace with extension, size, absolute-path, blocked-directory, and overwrite guards. Absolute paths are blocked. Each old_text value must match exactly once before mutation is allowed. dry_run should be used before mutation, and validation should run after mutation. This bridge must not be used to bypass approved workspace, validation, or audit boundaries.
