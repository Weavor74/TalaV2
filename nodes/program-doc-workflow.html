The Workflow Builder and Executor area documents Tala's structured workflow surface. It is used to list workflows, save workflow definitions, delete workflows, execute workflow graphs, and inspect workflow progress. Workflow documentation should explain triggers, steps, validation, execution status, and result reporting generically. It must not claim a workflow ran unless the approved workflow bridge returns a verified execution result.
