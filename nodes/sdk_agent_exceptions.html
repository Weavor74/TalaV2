exceptions.py — Tala Cognitive Engine Room: Agent SDK Custom Exceptions ======================================================================= All domain-specific exceptions raised by the Tala Agent SDK.

It lives at sdk/agent/exceptions.py within the agent SDK.

Classes it defines: TalaBaseError — Root exception for all Tala Agent SDK errors.; InvalidNodeSchemaError — Raised when an HTML Neural Node fails schema validation.; AuthorityBoundaryViolation — Raised when activation logic attempts to mutate a node's ``execution_authority`` field.; Mem0WriteBlockedError — Raised when a write to the Mem0 persistent memory layer is blocked.; InsufficientTokenBalanceError — Raised when an agent operation requires more tokens than are currently available in the session balance.; InsufficientEscrowError — Raised when an inter-agent or cross-boundary operation cannot be funded because the escrow account holds less than the required amount.; PiiAccessBlockedError — Raised when a node or pipeline attempts to read, write, or emit data that has been classified as Personally Identifiable Information (PII) without the appropriate access clearance.; StyleCapExceededError — Raised when a node's output exceeds the configured style or persona cap — for example, when a response exceeds the maximum permitted formality deviation, verbosity budget, or persona drift threshold.; SafetyGuardrailViolation — Raised when input prompts or model outputs violate configured safety guardrails..
