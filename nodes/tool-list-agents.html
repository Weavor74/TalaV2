Tool: list_agents

<p><strong>list_agents</strong> is a callable tool in Tala's registry. List the agent personas available to run swarm nodes as, with their ids and roles.</p><p>It takes no arguments: <code>list_agents()</code>.</p><p>Every persona a swarm node can be assigned to through ``agent_id``. Check this before creating one: reusing an existing persona is nearly always better than adding a near-duplicate.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
