memory.py — Tala Evidence Browser Backend ========================================= Implements the JSON-RPC methods for memory search, prompt injection defense, and unified research extraction.

It lives at python/harness/memory.py within the Python harness, the backend that runs the system.

Functions it exposes: handle_memory_search() — Search all active semantic indexes (node contents, external memories, etc.); handle_memory_session_search() — Search specifically within conversation sessions.; handle_memory_browse() — Return surrounding context for a given reference (e.g., surrounding turns).; handle_memory_record_completed_turn() — Save completed turn to conversation_turns and memory_index.; handle_memory_scan_context() — Scan text for prompt injection patterns.; handle_memory_reindex_node() — Reads an HTML Neural Node from disk, parses it, and stores it in the MemoryManager index.; handle_research_unified_search() — Unified search hitting both local memory and (simulated) web.; index_profile_chunks() — Helper to chunk profile JSON and insert into memory_index; handle_memory_reindex_profiles() — One-time migration to index existing user profiles into memory_index.; handle_research_distill_to_node() — Create a new Neural Node from selected research results.; handle_memory_save_node(); handle_memory_delete_node(); handle_memory_get_user_model() — Retrieve the reconstructed offline-first user memory model..
