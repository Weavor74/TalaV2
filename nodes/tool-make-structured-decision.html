Tool: make_structured_decision

<p><strong>make_structured_decision</strong> is a callable tool in Tala's registry. Get a fast, schema-constrained decision in a single forward pass -- faster and more reliable than reasoning in free text and parsing the answer. Use for classification, picking from a fixed set of choices, yes/no questions, or scoring -- including scoring several inputs at once in one call. Not for open-ended generation, explanation, or anything without a fixed small set of possible answers.</p><p>Call it as <code>make_structured_decision(schema*, contexts*, instructions)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>schema</code> (object, required)</li><li><code>contexts</code> (array, required)</li><li><code>instructions</code> (string, optional)</li></ul><p>Each key in `schema` is a field to decide, with a "type" (enum, boolean, integer, or number) and a required "description" -- the server refuses a field with no description. `contexts` is 1-256 input strings, each decided independently against the same schema in one batched call. `instructions` is shared guidance applied to every context. Refuses cleanly, with success: false, if the embedded engine is not currently running -- reason through the question directly instead of treating that as a hard failure.</p><p>Implemented in <code>sdk.agent.decision_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
