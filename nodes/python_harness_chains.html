Harness: Chains

chains.py — Ghost and Real are two chains, split by audience.

It lives at python/harness/chains.py within the Python harness, the backend that runs the system.

Functions it exposes: is_external() — Whether this belongs on the Real chain as well as the Ghost chain.; classify() — Which chains this transaction is written to.; record() — Record one transaction on the chains it belongs to.; index() — Record which chain a transaction belongs to.; index_sync() — Index a transaction from synchronous code.; ghost_endpoint() — The local chain node.; real_endpoint() — The configured shared-chain endpoint, or empty if there is none.; authorities() — Every signer whose blocks this install recognises.; cutoffs() — Signers that may no longer sign, and the block they stopped at.; set_authorities() — Set which signers may sign from now on.; active_authorities() — Signers that may sign right now.; flush() — Write every queued Real transaction, oldest first.; summary() — Counts for both chains, so the difference between them is visible.; reconcile() — Pull the shared chain and index what is on it that is not indexed here..
