Tool: chain_read

<p><strong>chain_read</strong> is a callable tool in Tala's registry. Look up one transaction on your local blockchain by its id and say whether it is really on-chain: its type, creator, counterparty, block, and whether it carries a document. Never returns document contents. Read-only.</p><p>Call it as <code>chain_read(tx_id*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>tx_id</code> (string, required)</li></ul><p>``tx_id`` is the transaction id (for example ``node-create`` ids such as ``node-<name>``, ``ghost_commit_<task>`` or ``peer-directory:<wallet>``). Returns ``found``, a summary of the transaction and its metadata, and the block it sits in.</p><p>Implemented in <code>sdk.agent.chain_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
