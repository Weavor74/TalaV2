Tool: run_python

<p><strong>run_python</strong> is a callable tool in Tala's registry. Run Python 3 code (pass code) or a .py file (pass script) in your own Python venv on your computer and get its output. cwd defaults to the workspace. Your workspace is your own working folder on this computer (D:\TalaWorkspace unless configured otherwise); relative paths are relative to it. Risky actions are held for the user's approval; deny-listed places are blocked.</p><p>Call it as <code>run_python(code, script, args, cwd, timeout_seconds)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>code</code> (string, optional)</li><li><code>script</code> (string, optional)</li><li><code>args</code> (array, optional)</li><li><code>cwd</code> (string, optional)</li><li><code>timeout_seconds</code> (integer, optional)</li></ul><p>Implemented in <code>sdk.agent.workstation_tools</code>.
