Tool: import_skill_md

<p><strong>import_skill_md</strong> is a callable tool in Tala's registry. Import an agentskills.io-format SKILL.md (from a file path or URL) as an HTML-NN skill knowledge node so its instructions become recallable context.</p><p>Call it as <code>import_skill_md(source*, max_body_chars)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>source</code> (string, required)</li><li><code>max_body_chars</code> (integer, optional)</li></ul><p>Accepts a local file path or an http(s) URL to a SKILL.md document (agentskills.io open standard: YAML frontmatter with name/description plus a markdown instruction body). The skill is persisted as a schema-valid HTML-NN learning node tagged 'skill' so graph activation surfaces it when relevant. Bodies longer than ``max_body_chars`` are clipped, and the clip is reported in the result rather than applied in silence.</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
