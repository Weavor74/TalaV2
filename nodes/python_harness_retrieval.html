retrieval.py — Tala Cognitive Engine Room: Semantic Node Retrieval Engine ======================================================================= Crawls the nodes directory, parses HTML Neural Nodes, and performs a local, offline-first Semantic RAG similarity search using ChromaDB.

It lives at python/harness/retrieval.py within the Python harness, the backend that runs the system.

Functions it exposes: index_nodes() — Parse new or modified HTML Neural Nodes and embed them into ChromaDB incrementally.; retrieve_relevant_nodes() — Search for relevant nodes using ChromaDB vector similarity, and multiply the raw cosine similarity score by the node's confidence and relevance weights..
