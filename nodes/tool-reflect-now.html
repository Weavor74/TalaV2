Tool: reflect_now

<p><strong>reflect_now</strong> is a callable tool in Tala's registry. Run a self-reflection cycle now: read own health and verify own documentation, apply any repair that is registered for what was found, and report findings that have no automatic repair. Returns what was seen and what was done.</p><p>Call it as <code>reflect_now(minutes, dry_run_first)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>minutes</code> (integer, optional)</li><li><code>dry_run_first</code> (boolean, optional)</li></ul><p>Observes health and documentation, repairs what has a registered repair, records the rest. Same cycle the scheduler runs hourly, with the same guardrails; this only changes when it happens. Does not reset the scheduled interval, so an on-demand cycle cannot be used to starve the automatic one.</p><p>Implemented in <code>sdk.agent.reflection</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
