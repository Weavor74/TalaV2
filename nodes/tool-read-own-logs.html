Tool: read_own_logs

<p><strong>read_own_logs</strong> is a callable tool in Tala's registry. Read Tala's own event log: RPC failures, warnings and errors recorded by the harness. Filter by level, by substring, or by how far back to look. Read-only -- Tala cannot clear or archive her own logs.</p><p>Call it as <code>read_own_logs(levels, search, minutes, limit)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>levels</code> (string, optional)</li><li><code>search</code> (string, optional)</li><li><code>minutes</code> (integer, optional)</li><li><code>limit</code> (integer, optional)</li></ul><p>Defaults to errors and warnings from the last hour, because INFO is tens of thousands of rows on a real install and drowns whatever is being looked for. Each entry carries the failing RPC method and its trace where one was recorded, so "something broke" becomes "auth.get_credentials raised KeyError". Read-only by design (Q-19: "She cannot clear her logs but I should be able too"). An agent that can erase the record of what it did is not auditable.</p><p>Implemented in <code>sdk.agent.self_diagnosis</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
