Tool: control_swarm

<p><strong>control_swarm</strong> is a callable tool in Tala's registry. Pause, resume or cancel a running swarm by its parent task id. Cascades to every node the swarm dispatched.</p><p>Call it as <code>control_swarm(parent_task_id*, action*)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>parent_task_id</code> (string, required)</li><li><code>action</code> (string, required)</li></ul><p>action is one of pause, resume, abort. start_swarm could launch work that nothing could then stop: the swarm.pause / resume / cancel methods existed and had no caller anywhere. Being able to start something without being able to stop it is worse for the agent than for a person, because she cannot see the task queue. Cascades. task.control acts on the parent and every child, so a swarm parent takes all of its dispatched nodes with it.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
