SDK Agent: Sandbox

sdk/agent/sandbox.py — OS-level isolation adapters for workstation commands. Linux uses BubblewrapSandbox (bwrap) or NamespaceContainerSandbox (unshare); macOS uses MacOSSandbox (sandbox-exec -p, deprecated but still functional); Windows uses WindowsSandbox job objects via ctypes. Job objects do not confine filesystem or network; those stay policy-only, labeled job-object or guarded-policy-only. LocalSandbox still executes host commands through AsyncShellExecutor.

It lives at sdk/agent/sandbox.py within the agent SDK.
