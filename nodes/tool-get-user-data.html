Tool: get_user_data

<p><strong>get_user_data</strong> is a callable tool in Tala's registry. Retrieve user data fields from the A2UI state manager.</p><p>Call it as <code>get_user_data(field_name*, permission_token)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>field_name</code> (string, required)</li><li><code>permission_token</code> (string, optional)</li></ul><p>Checks the A2UI State Manager. If the field is PUBLIC, returns it. If the field is SECURED, requires confirmation via permission_token. On missing token, triggers ACCESS_DENIED and logs to the Ghost Ledger.</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
