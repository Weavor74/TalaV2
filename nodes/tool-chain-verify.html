Tool: chain_verify

<p><strong>chain_verify</strong> is a callable tool in Tala's registry. Independently re-verify your whole local blockchain from its file: every block's hash, the links between blocks, every signature, and that each signer is a permitted authority. Reports whether it is valid and lists any problems. Slower than chain_status; read-only.</p><p>It takes no arguments: <code>chain_verify()</code>.</p><p>Reads ``chain.json`` directly and runs the same verifier the shared-chain import uses, so it agrees with the node only if the ledger genuinely is sound. Reports ``valid``, ``height``, signed and unsigned block counts and up to 20 problems. Refuses a file over 256 MB rather than loading it.</p><p>Implemented in <code>sdk.agent.chain_tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
