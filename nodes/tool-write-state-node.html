Tool: write_state_node

<p><strong>write_state_node</strong> is a callable tool in Tala's registry. Record current conditions into a state HTML-NN, creating it if needed. Merges into whatever it already holds.</p><p>Call it as <code>write_state_node(node_id*, values*, title)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>node_id</code> (string, required)</li><li><code>values</code> (string, required)</li><li><code>title</code> (string, optional)</li></ul><p>Merges ``values`` into the node rather than replacing it, so two writers recording different facts do not erase each other. A caller wanting a key gone sets it to null explicitly. Creating a state node needs no admission: it holds data, and the gate exists for code.</p><p>Implemented in <code>sdk.agent.node_execution</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
