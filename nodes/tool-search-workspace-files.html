Tool: search_workspace_files

<p><strong>search_workspace_files</strong> is a callable tool in Tala's registry. Search the text of the project's own files (source, configuration, scripts, documentation) for a string or regex pattern. This reads the codebase only and knows nothing about the person you are talking to: anything personal, such as what they told you, their belongings, people or preferences, is in search_memory, not here; a match in a project file is never a fact about them.</p><p>Call it as <code>search_workspace_files(query, file_pattern)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>query</code> (string, optional)</li><li><code>file_pattern</code> (string, optional)</li></ul><p>Fast, cross-platform native Python search across workspace files.</p><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
