Tool: read_own_health

<p><strong>read_own_health</strong> is a callable tool in Tala's registry. Read Tala's own measured subsystem health: which of the twelve services are healthy, degraded, critical or unmeasured, and the evidence behind each verdict. Use this before claiming a subsystem works or does not.</p><p>It takes no arguments: <code>read_own_health()</code>.</p><p>Returns the same measured state the LOGGING panel shows, including the reason for each verdict -- "8 of 8 providers online", "no MCP servers configured" -- so a diagnosis can cite evidence rather than a colour. A subsystem nothing can measure reports UNKNOWN, never HEALTHY, and an UNKNOWN present makes the overall verdict PARTIAL rather than rounding up to healthy.</p><p>Implemented in <code>sdk.agent.self_diagnosis</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
