Harness: Storage Clients

storage_clients.py — storage providers become an option that actually exists.

It lives at python/harness/storage_clients.py within the Python harness, the backend that runs the system.

Classes it defines: Capability — What one provider type needs, and whether it is usable right now. (methods: dependency_present(), available(), describe()); StorageError — A storage operation failed, with a reason fit to show a person.; FolderClient — A local or network directory. (methods: probe(), put()); FtpClient — FTP or FTPS via the standard library. (methods: probe(), put()); WebdavClient — WebDAV over httpx, which is already a dependency. (methods: probe(), put()).

Functions it exposes: capabilities() — Every provider type, and whether it can be used right now.; normalise_kind() — Map a panel's provider_type string onto a capability key.; assert_reachable() — Check a remote storage target against the network guard.; get_client() — A client for one configured provider, or a refusal that says why..
