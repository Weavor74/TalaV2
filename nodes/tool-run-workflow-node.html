Tool: run_workflow_node

<p><strong>run_workflow_node</strong> is a callable tool in Tala's registry. Execute a multi-step JSON workflow graph defined in an HTML Neural Node. Use this tool to progress through interactive node-based workflows step-by-step. Actions available: 1. 'start': Starts the workflow. Requires 'node_id'. 2. 'step': Submit data for the current step. Requires 'node_id' and 'value'. IMPORTANT: You MUST follow the instructions returned by each step! If a step asks you to prompt the user, DO NOT guess the answer. Ask the user!</p><p>Call it as <code>run_workflow_node(action, node_id, value)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>action</code> (string, optional)</li><li><code>node_id</code> (string, optional)</li><li><code>value</code> (string, optional)</li></ul><p>Implemented in <code>sdk.agent.tools</code>.
