Tool: run_workflow_node

<p><strong>run_workflow_node</strong> is a callable tool in Tala's registry. Execute a multi-step JSON workflow graph defined in an HTML Neural Node. Use this tool to progress through interactive node-based workflows step-by-step. Actions available: 1. 'execute' or 'start': Runs a saved workflow. node_id accepts its exact name, flow ID or HTML-NN ID. Pass inputs as a JSON object. 2. 'step': Submit data for the current step. Requires 'node_id' and 'value'. For saved workflows, always pass the user's inputs explicitly, for example inputs={"numbers": [11, 4, -3]}. A JSON-encoded object in value is also accepted. Never omit user-supplied inputs or substitute the script's defaults. IMPORTANT: You MUST follow the instructions returned by each step! If a step asks you to prompt the user, DO NOT guess the answer. Ask the user!</p><p>Call it as <code>run_workflow_node(action, node_id, value, inputs)</code>, where <code>*</code> marks a required argument:</p><ul><li><code>action</code> (string, optional)</li><li><code>node_id</code> (string, optional)</li><li><code>value</code> (string, optional)</li><li><code>inputs</code> (string, optional)</li></ul><p>Implemented in <code>sdk.agent.tools</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
