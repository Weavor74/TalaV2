Tool: discover_mcp_servers

<p><strong>discover_mcp_servers</strong> is a callable tool in Tala's registry. Scan this machine's other MCP clients for servers already configured there. Read-only: reports what it finds and connects nothing.</p><p>It takes no arguments: <code>discover_mcp_servers()</code>.</p><p>Reads the config files kept by Claude Desktop, Claude Code, Cursor, Windsurf and VS Code, plus project-local .mcp.json, and reports the servers defined in them. Each result says whether Tala already has that server registered. Connects to nothing. Adopting a server runs a subprocess with the invoking user's privileges, which is a decision for Weavor rather than something a scan should do on its own. Environment blocks are reported only as a has_env_secrets flag, never echoed.</p><p>Implemented in <code>sdk.agent.agent_authoring</code>. The Python registry remains what actually executes; this node is the catalogue entry that makes the tool retrievable and referenceable from a workflow.</p>
